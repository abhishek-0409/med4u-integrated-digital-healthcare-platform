# Demo doctor portraits

These four locally bundled JPEGs are AI-generated fictional portraits for demo profiles only.
They must not be used to represent a verified or real clinician. The app selects one only
when a demo doctor record includes an explicit `male` or `female` gender from the API; selection
is stable per doctor ID. Unknown gender and missing photos on real profiles use the neutral
initial fallback. The source images were resized to 384x480 JPEG at quality 86 for mobile use.
